# Lettertypes

- **Andika-Regular.woff2**: Andika 7.000 van SIL Global, onveranderd overgenomen uit de officiele uitgave (https://software.sil.org/andika/). Licentie: SIL Open Font License 1.1, zie `OFL-Andika.txt`. "Andika" is een gereserveerde lettertypenaam: een aangepaste versie (bijvoorbeeld verkleind tot alleen de Latijnse tekens) moet een andere naam krijgen. Daarom staat hier het originele bestand.

Lettertypes worden meegeleverd met de app en nooit van een externe server geladen (privacy).
